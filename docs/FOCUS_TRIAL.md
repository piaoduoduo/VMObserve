# 主线实验任务与试用记录

## 学生任务单

打开实验台首页，进入 3.2 的地址归属练习。查看三个返回指针和映射区间，填写每个指针归属及相关映射 RSS，提交后在 `smaps` 中找出你用的区间与 `Rss`。记下申请量、映射大小与驻留量的含义。

切到 3.3 大页对照，选择写到四分之一。预测哪组可能记录更少的次缺页，以及两组 RSS 如何变化。「记录预测并读原文」会保存预测草稿并打开原文区。分别在 JSONL 查 `madvise` 的返回值，在 JSONL 的本步 `sample` 行查 `action_minor`，在两组 `smaps` 查目标映射的 `Rss` 与 `AnonHugePages`。完成三项判断，再查看采样汇总并解释。最后导出 HTML 报告，可把已保存的 3.2 笔记一并导出。

## 试用组织

建议邀请 3–5 名已学习分页且首次使用工具的同学。按以下顺序进行，每轮都记录开始与结束时间、答案和用过的提示。

1. **使用前**。给学生一份未上页面的真实 `malloc` 记录，在三个指针与原始 `smaps` 中找出相关映射并算 RSS。提前准备相同格式的材料。
2. **练习**。按上面的任务单使用作品，不公布迁移题答案。
3. **迁移**。3.2 换一轮真实样例，独立写出首地址归属和 RSS 统计范围。3.3 换另一环境或另一轮，先看「申请内存」，再看一个写入阶段。从原文作答后提交三项判断，记录首次答对几项、查阅的字段与使用的提示。要求用一句话说明建议返回值和实际驻留量各能证明什么。
4. **复核**。记录反复出现的错误，修正最常见的一项，再用一份不同记录短测。小样本用每人的观测与典型答卷说明体验，不计算推广到整班的效果。
