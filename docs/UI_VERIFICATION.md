# 界面设计与浏览器核对

概念图：`output/design/concept.png`，内置 ImageGen 生成。实现：原生 HTML/CSS/ES module + Python 本机服务，全部控件和数据为代码渲染，概念图没有当作实验截图使用。

设计提要：中文虚拟内存实验观察台；白色背景、墨色文本、青绿色强调；顶部动作按钮，左侧历史，中央程序动作/数据，右侧诊断与复验；避免装饰插画和无依据的成功指标。

IAB 原生截图：`output/verification/workbench-final-desktop.png`；手机版：`output/verification/workbench-final-mobile.png`。桌面请求 1488×1056，与概念图尺寸对应；手机请求 390×844，滚动条使最后文档有效内容宽度为 375，未发生页面横向溢出。测试后已清除 viewport override。

本轮已用 view_image 同时查看概念、最终桌面和最终手机截图。主布局、色彩、组件与层次依照设计实现；以下真实业务需求导致的文案/密度差异均保留，不宣称逐像素完全一致。

| 比较点 | 核对结果或有意差异 |
| --- | --- |
| 布局 | 保留顶部动作、历史侧栏、主题标签、左图表右解释；手机转单列，历史横向列表 |
| 色彩 | 白背景、teal 主按钮/大页条、slate 对照条、浅琥珀证据边界；没有添加装饰图片 |
| 字体 | 桌面加大标题、产品名和诊断正文；系统中文字体取代概念图字形，控件单独设字号 |
| 比较图 | 数据驱动条宽，64 KiB 按真实比例显示为很短的线；0 不假装有可测驻留，数值标签为准 |
| 真实文案 | 诊断使用带条件、指标和局限的规则文本，替代概念图的简写；“512 倍”紧邻左侧对照表 |
| 来源与状态 | 增加真实 ID、旧格式标识和最近任务状态栏，明确它是否对应当前所选历史，避免误报 |
| 原始证据 | 原图的折叠入口保留；修复了 hidden 被 flex 样式覆盖导致按钮提前显示的问题 |
| 首屏文案比对 | 标题、导航与三个主要动作一致；增加执行状态/ID，展开为完整证据解释；没有增加营销标语 |
| 交互 | 稀疏与逐页复验都产生了真实新记录；历史播放只改变显示步骤；原文弹窗与下载实际可用 |

最终检查没有发现遮挡、控件裁切或手机整页溢出。历史数量与任务状态使页面比单张概念图更长，底部源码清单需要滚动，这是有意保留真实状态信息的差异。后续可进一步提升数据图可读性，但不要为贴合静态图删掉来源、失败或限制说明。
