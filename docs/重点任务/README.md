# 重点任务目录

在项目根目录运行 `python work/launch.py`，打开[网页目录](http://127.0.0.1:8765/labs/focus)。

| 实验 | 课内任务 | 在实验台看什么 |
| --- | --- | --- |
| [3.2 连续申请与释放](http://127.0.0.1:8765/labs/3.2?replay=sequence) | 指导书第 10–11 页。运行给定的 malloc.c，暂停时读 maps 或 status，比较大小块申请和释放。自行设计堆增长程序列在拓展。 | 把三个指针分别放回 smaps 的地址范围，用 strace 找到对应的 brk 或 mmap。同一段映射的 RSS 只加一次。 |
| [3.3 按需调页](http://127.0.0.1:8765/labs/3.3?replay=demand512) | 第 11–12 页。运行 demand.c，分阶段用 ps 观察缺页变化。第（2）项还要求仿照示例尝试设计内存访问程序。 | 先比较申请和第一次写入，再用[五次 ps](http://127.0.0.1:8765/labs/3.3#original-demand)核对整进程的变化。在[实验笔记](http://127.0.0.1:8765/lesson)分别记录 16 MiB 对照样例和自己实际运行的程序。 |
| [3.3 栈增长与溢出](http://127.0.0.1:8765/labs/3.3?replay=stack) | 第 12 页。运行递归样例，调整栈上限，比较普通缺页和栈溢出。自行编写递归或大局部数组程序列在拓展。 | 选两组栈上限，比较递归深度、驻留量和退出信号。项目使用自编递归程序采样。 |

报告模板为每项实验留了「实验过程与结果」「思考题回答」「拓展」三栏。写报告时注明程序、观测阶段和统计范围。512 MiB 进程的 ps、目标映射的 smaps 和自己另写程序的结果应分别标明。

上述要求取自本学期学生版《应用层实验文档》和《应用层实验报告模板》。往届资料入口有 [1037 Wiki](https://1037.wiki/) 和[华科计算机学院实验资料](https://github.com/Justin-Xiang/HUST_CS)。本次在 1037 Wiki 读到公开首页，未取得与本期相同的指导书。
