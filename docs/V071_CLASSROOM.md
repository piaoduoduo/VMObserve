## 首次独立试用

请找一位没有参与实现的人独立完成。先写第 1 题，再打开网页。预计十分钟；记录实际用时。不要把自动检查或团队演示当成学习者回答。

1. **预测。** 一段程序依次申请三块不同大小的内存，同时保留，但不主动向里面写数据。你预计会看到几个映射？已驻留的内存会等于申请量吗？为什么？
2. **观察。** 打开 3.2，点第④个圆，记下第三次申请后还有几块内存、落在几段映射里，合计驻留多少。轮流点 p2 和 p3，看看图里亮起哪一段、下面亮起哪一行。在「查看实测依据与原文」里找出支持你判断的地址区间。
3. **解释。** 哪个观测改变了你的预测？为什么不能把整个映射的驻留量分别算给每个对象再相加？单凭这一轮，还不能推断哪件事？
4. **自己复做。** 有 Linux 环境时，按第⑥步的双终端指南运行课内程序。在第三次申请暂停时，用你拿到的三个指针去查自己的 maps，写下哪些在同一段和判断依据。记录来自网页还是自己的终端，以及哪一步需要提醒。
