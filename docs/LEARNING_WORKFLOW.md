# 回放对照与学习笔记

## 对照同一步的不同实验

打开 3.2 连续 malloc、3.3 按需调页或栈增长、按需分配课例、写时复制回放。在一个具体采样步骤下，展开「把本步与另一轮实验并排对照」。

1. 选择当前记录中的另一案例，或切换到工作台已有的另一份同类记录。
2. 先核对参数差异、系统、内核、基础页大小、分配器环境变量和大页设置。两次采样的环境与程序可能不同，差值本身不证明原因。
3. 对照相同阶段的读数。写时复制按父／子角色匹配；栈增长比较最后采到的递归快照，深度不同时会提示。
4. 差值统一为「对照 − 当前」。未采集的读数显示为未采集，不填成零。连续 malloc 使用解析器按 VMA 去重后的 RSS；释放后存活块申请量为零，旧地址对应的堆映射仍可能保留。
5. 可打开对照实验核对原文，或导出当前对照 JSON。文件保留两份记录编号、报告与源码哈希、参数、环境、检查状态和实际采样。

对照入口按需读取其他记录；没有可匹配的阶段时不计算差值。透明大页继续使用原有的两组配对视图。

## 记录和恢复回答

每个实验回放页底部有「记录本步的预测、观测与解释」。

- 草稿按报告哈希、实验类型、案例和步骤区分，输入后保存在当前浏览器。
- 「保存这一步的笔记」生成独立版本，带上当时采样、案例编号、原文路径和报告哈希。
- 展开「已保存的笔记」，可搜索回答或只看当前记录。复制旧笔记到本步草稿后，可以撤销这次替换；独立保存的版本保持原样。
- 「返回对应实验」会先核对工作台是否有该记录、报告哈希是否一致，再定位案例与步骤。导入文件中的外部网址不会用于跳转。
- 编辑笔记或操作对照时，自动播放会暂停，避免输入框被下一帧替换。

这些是个人预测和解释，保持未评分。

## 备份与迁移

「导出全部笔记」包含已保存的版本、各步草稿和当前输入。浏览器不允许访问存储时，仍可导出本页可用的草稿，并在文件中标明历史记录不可读取。

到另一浏览器打开实验台，点击「导入笔记」，选择导出的 JSON：

- 同编号、同内容的笔记跳过，避免重复。
- 同编号、不同内容时停止整次导入。
- 本地已有草稿优先保留。
- 写入空间不足时撤回本次新增条目；若浏览器连撤回也拒绝，会明确提示需要检查的范围。
- 单文件上限 20 MiB，最多 10,000 条已保存笔记和 10,000 份草稿。
- 兼容早期只有已保存笔记和当前草稿的 v1 导出文件。

导入恢复的是回答和随附采样快照。返回原始实验仍需要工作台具有对应实测文件。浏览器存储按地址与端口隔离；换端口时，可通过导出、导入迁移。

遇到损坏条目，普通导出会停止并显示提示；历史列表提供「导出原始备份」保留存储原文，用于排查。原始备份不能作为普通学习笔记直接导入。

界面验证使用 ?verification=1 和独立存储空间，导出标记为 ui_verification；普通个人笔记标记为 learner_notes。两类文件分别导入，自动化界面检查不计为真实学习者试用。

## 开发验证

运行现有 Python 检查和笔记／对照逻辑测试：

~~~sh
python -m unittest discover -s tests -q
node --test tests/test_notes_store.mjs tests/test_comparison_data.mjs
~~~

Node 仅用于开发测试，回放服务仍只需 Python。2026-11-19 本轮结果：Python 66 项、Node 27 项通过。真实浏览器另检查导入恢复、搜索与撤销、跨记录对照、手机宽度、存储失败和原有课程流程；未新增 Linux 探针运行或教学效果数据。
