## 每轮复评的最小核对

先从干净检出运行 `python -B work/verify_submission.py`。保留输出 JSON 和实际验收提交。该命令完成历史样例的数据复核，课堂答卷和新环境采集需另行记录。

1. 3.2 打开内置 openEuler 记录 `20261118T013159.221864Z` 的 `sequence-1` 第三次申请。对照原始 `smaps`，按相关 VMA 去重算出 4 + 12 = 16 KiB。核对回放页、学习报告和 HTML 导出的范围。对跨 VMA 的构造用例，指针首地址只属于一段，块范围可以与多段相交。
2. 3.3 用 openEuler `20261120T120355.446473Z` 与 WSL2 `20261120T113225.827429Z` 的同一阶段作复核。各环境内两组写到四分之一时 RSS 均为 128 MiB，次缺页为 32768 与 64。释放后两组都无目标映射，映射指标应为空，进程级缺页读数仍按采样显示。
3. 试用和独立复现只按已记录的参与者反馈和实际运行结果评分。保留受测版本、环境、检查方式、扣分点及复评结论，下一轮沿用同一尺度。
