# 这套工具在操作系统课里怎么用

适用对象：学过指针、进程和分页，正要做 openEuler 应用层实验的学生。当前重点是指导书 3.2–3.3。完成这一课的标志，是学生能从自己的数据解释一个现象，再改变一个条件复验。能播放示例是起点。

## 两份真实记录为什么会给出不同的 RSS

- 课内原版：11 月 18 日 openEuler 客户机的普通用户运行，PID 1299。原程序在同一进程五次暂停；第二终端取 ps 的 MINFL/MAJFL/RSZ/VSZ。申请前、刚申请 512 MiB 和全部写完，进程驻留为 **1428、1432、525716 KiB**。原始行、程序哈希和内核版本随[记录](../work/lessons/demand/original-ps.json)保存。
- 首页的连续分配是另一个程序、另一轮运行。“相关映射”只对与目标块相交的 VMA 求和，同一 VMA 算一次。不能用课内原版的进程 RSS 减去首页的映射 RSS 来推算其他内存。
- 实践写作按模板走：**实验过程与结果 → 思考题回答 → 拓展**。动手页可以记录、保存、导出这三项，绑定当前选中的案例与阶段。本人操作、个人 Git 记录和 AI 使用说明按课程格式模板补充，报告工作稿保持原样。
